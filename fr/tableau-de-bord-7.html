Documentation

Tableau de bord

Le tableau de bord constitue le point central de contrôle pour l'administration de votre espace de création d'applications. Cette page vous offre un accès rapide aux fonctionnalités essentielles, facilitant la gestion de vos applications et la navigation à travers les différents aspects de la plateforme.

Mes applications

La page d'accueil du tableau de bord affiche vos applications sous forme de grille ou de liste, avec un champ de recherche pour les retrouver rapidement. En haut de la page, trois encarts donnent accès au forum, aux dernières nouveautés et aux tutoriels vidéo.

Actions disponibles

  • Créer une nouvelle application avec la tuile « Créer une application »
  • Supprimer une application existante
  • Cloner une application pour gagner du temps dans le développement ou bien faire une sauvegarde
  • Éditer les paramètres et les fonctionnalités de chaque application

Applications publiées

Le menu « Publiées » permet de visualiser et gérer les applications publiées.

Fonctionnalités

  • Liste complète des applications publiées et leur statuts
  • Dates de publication
  • Lien directe vers les applications

Applications partagées

Le menu « Partagées » regroupe les applications partagées, pour collaborer avec d'autres créateurs et étendre les fonctionnalités de vos propres projets.

Possibilités

  • Accédez aux applications partagées par d'autres utilisateurs
  • Collaborez sur des projets communs
  • Partagez vos applications pour encourager la collaboration

Audience

Le menu « Audience » présente les données analytiques pour comprendre le comportement des utilisateurs, les performances des applications et prendre des décisions éclairées. Suivez les statistiques d'utilisation et assurez vous que vos utilisateurs bénéficient toujours de la meilleure expérience.

Analyses proposées

  • Suivi des utilisations et installation de vos applications
  • Suivi des utilisateurs actifs
  • Évaluation des performances des fonctionnalités

Communauté

La rubrique « Communauté » du menu rassemble les ressources pour apprendre et échanger.

  • Tutoriels : les tutoriels vidéo pour maîtriser chaque fonctionnalité, de la création d'applications à l'intégration avec des systèmes tiers.
  • Documentation : des informations détaillées sur chaque aspect de la plateforme, pour vous guider à chaque étape.
  • Envoyer un avis : signalez un bug ou un dysfonctionnement, et partagez vos suggestions. Tous les retours sont lus.
  • Rejoindre le forum : posez vos questions, échangez avec d'autres utilisateurs et découvrez les dernières nouveautés.
  • Quoi de neuf : les annonces de nouvelles fonctionnalités, astuces et bonnes pratiques.

Compte

La rubrique « Compte » regroupe la gestion de votre espace.

  • Gérer la facturation : votre abonnement et vos factures.
  • Mon compte : les informations de votre compte.
  • Déconnexion : quitter votre session.
