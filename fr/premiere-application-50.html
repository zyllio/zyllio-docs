Créer un compte

Vous pouvez créer un compte gratuitement sur Zyllio pour commencer. Chaque plan offre un panel de fonctionnalités différentes. Si vous voulez débuter avec la conception d'application mobile sur Zyllio, le plan gratuit est un excellent choix et propose déjà une multitude d'options. Vos applications et vos données sont hébergées en France. La création d'un compte se fait en quelques secondes.

Rendez-vous sur la page d'accueil du site de Zyllio : https://zyllio.fr/

A présent cliquez sur le bouton Commencer gratuitement, en haut à droite. La page de connexion s'affiche : pour créer votre compte, cliquez sur S'inscrire.

Vous pouvez aussi vous connecter directement avec votre compte Google. Le tour est joué, vous devriez arriver sur votre Tableau de bord ! Dans la prochaine section, nous préparerons le terrain pour démarrer notre première application !
